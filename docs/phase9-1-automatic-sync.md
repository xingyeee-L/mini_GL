# 阶段 9.1：常用目录与自动同步

## 已实现边界

- 文档、下载、桌面必须由用户逐项勾选并再次确认授权，三个目录分别注册为数据源。
- 注册仅保存规范化目录和计划，不枚举文件、不解析正文、不建立索引。
- 支持仅手动、每小时、每天；计划可以按数据源修改。
- 自动任务严格复用安全扫描、原子文件快照、增量关键词索引和本地 BGE 索引。
- 同一数据源只允许一个 RUNNING 同步；重复触发失败关闭。
- 电池供电时可跳过本轮并在 15 分钟后重试。
- 调度状态只保存时间、状态和截断错误，不写日志，不上传，不修改原文件。

## 运行语义

调度器随 `serve` 或 `desktop` 启动，每 30 秒检查一次已到期计划。mini_GL 未运行时不会
在后台读取文件；重新启动后，已过期计划会在首次检查中执行。向量模型不可用时本轮标记
失败，下一个周期重试，不会切换到云端模型。
