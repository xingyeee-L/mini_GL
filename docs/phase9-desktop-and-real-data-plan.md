## 真实资料准入步骤

1. 用户在“控制台 → 数据与索引”填写自己明确选择的目录。
2. 用户确认拥有目录中资料的使用权限。
3. 系统只注册规范化根目录，不在注册动作中扫描正文。
4. 用户主动点击同步后，系统按原有只读安全扫描策略处理已批准的常用文件格式。
5. 同步完整成功后才提交文件状态；失败整轮回滚。
6. 用户主动建立关键词和 BGE 索引后，资料才进入搜索与本地回答。

## 完成标准

- 双击入口能可靠启动并展示可操作的恢复提示。
- 用户不使用命令行即可诊断、备份、恢复和准入资料。
- 跨数据源结果保持来源和权限隔离。
- 卸载或撤销前能列出所有应用自有派生数据，且绝不删除原始资料。
- 第一个真实导出器经过专项审查后才从“预留”变为“支持”。
